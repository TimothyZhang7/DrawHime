# LoRA 分阶段训练流程

## 状态顺序

1. 创建数据集并上传 5–200 张图片。
2. 选择角色、画风或概念模式，创建持久化自动打标任务。
3. `training-worker` 逐图读取独立对象存储，调用已配置的多模态提示服务生成英文 Caption；刷新页面可恢复进度。
4. 用户逐图检查并编辑 Caption，随后显式确认。图片增删会使旧确认进入 `stale`，Caption 修改会回到待确认。
5. 只有图片快照一致、全部 Caption 非空且最近打标任务已确认时，API 才接受训练任务。
6. 训练参数固化到任务并原样进入 GPU Runtime；失败重试复用同一快照和参数。

## 动态计价

训练产品后台价格是单个计价单位价格。API 根据图片数量、重复次数、Epoch、分辨率和 Rank 计算工作量，每 800 标准工作量向上取整为一个计价单位，范围为 1–32。试算接口和任务创建调用同一计算函数，主站资金预留使用该单位数量，因此页面价格与实际扣费保持一致。

## 可调参数

- 模型容量：Rank、Alpha。
- 训练强度：Epoch、重复次数、分辨率、学习率。
- 优化过程：学习率调度器、预热比例、梯度累积。
- Caption：随机打乱、保留前置 Token 数、Caption Dropout。
- 稳定性：随机种子、最大尝试次数和训练后测试提示词。

运行时固定使用 Anima 官方网络模块、BF16、梯度检查点和磁盘缓存；用户参数不允许覆盖模型路径、输出路径、服务凭证或 GPU 隔离配置。
