# DrawHime Desktop 发布验证矩阵

## 1. 文档职责

本文件持久记录桌面安装包在真实 Windows、DPI、GPU、网络和存储环境中的验收证据。`docs/desktop-design.md` 定义目标，本文件记录实际结果；没有证据的项目保持“待验证”，不得据此创建正式 GitHub Release。

状态只使用：

- `通过`：在所列真实环境执行并保存了可复现结果。
- `失败`：已经复现，必须修复并重新执行同一门禁。
- `待验证`：尚无覆盖该环境的直接证据。

## 6. Release 判定

当前状态：**已达到正式 Release 门禁**。

`v0.1.7` 已完成正式 Release。表中其余“待验证”属于后续扩展兼容性采样，不覆盖已经通过的 Windows 11 实机、Windows 2022/2025 安装门禁、无 GPU 能力锁定、RTX 4060 生成/训练、弱网断点和磁盘预检逻辑证据。下一轮优先补充 Windows 10/11 多 DPI、4/6/12/16/24 GiB 显存、WebView2 旧版、磁盘写满与睡眠恢复实机样本。
