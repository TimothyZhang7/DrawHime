# 安全策略

## 报告漏洞

安全问题请通过 GitHub Security Advisory 私下报告，并提供受影响版本、复现步骤、影响范围和建议修复方式。请勿在公开 Issue 中粘贴访问令牌、数据库连接串、用户媒体或生产日志。

## 敏感数据

- `.env`、`.private/`、数据库备份、对象存储数据和模型权重禁止提交。
- Token、卡密和会话凭证必须只保存哈希或进入一次性响应。
- GPU Runtime、数据库、Redis 和对象存储管理端口应限制在回环或私有网络。
- 钱包最终写入、任务终态和退款必须保持事务化或幂等。

## 支持范围

安全修复优先进入默认分支。部署自定义修改时，请先在隔离环境验证迁移、权限和退款链路。
