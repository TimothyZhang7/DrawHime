# LoRA 打标工具设计

## 目标

主站工具中心新增独立的 LoRA 打标页面。用户可以创建训练集、一次选择任意数量图片、启动逐图自动打标、查看中英文标签对照、删除或增加标签并保存。保存后的训练集直接出现在独立本地模型平台的 LoRA 训练页面，不复制数据库或媒体。

## 数据边界

- 训练集、图片、Caption、打标阶段与确认状态仍由独立本地模型平台负责并写入其独立数据库和对象存储。
- 主站页面使用现有主站 JWT 交换短期独立平台会话，然后通过同源 `/local-model-api` 调用真实训练集接口。
- 主站不新增训练图片表，不复制对象存储文件，不接触训练 Runtime、余额或 LoRA 产物。
- 单个数据集继续遵守独立平台最多 200 张图片、单图 25MB、短边至少 256 像素及 SHA-256 去重约束；“任意张数上传”表示一次可选择多张并由前端受控并发完整处理，而不是固定单张或固定小批次。

## 操作流程

1. 用户在主站工具中心进入“LoRA 训练打标”。
2. 页面交换或复用当前账号的独立平台会话，并读取该账号已有训练集。
3. 用户创建训练集并批量上传图片；服务端统一方向、色彩空间和 WebP 存储。
4. 用户选择角色、画风或概念重点，启动持久化自动打标；刷新页面后继续显示进度。
5. 自动打标完成后，页面把 Caption 拆成可操作标签。用户可以添加、删除标签，按图片保存到独立平台后端。
6. 翻译功能批量返回英文标签的简体中文对照，只辅助检查，不把中文写入训练 Caption。
7. 用户确认全部标签后，训练集进入 `confirmed` 状态，并可跳转到独立平台 LoRA 训练页继续设置训练参数。

## 稳定性与性能

- 图片上传使用有限并发并保留逐文件成功/失败统计；单张失败不丢弃其他已成功图片。
- 自动打标沿用独立平台数据库任务，训练 Worker 逐图持久化进度和结果。
- 页面仅在打标任务处于排队或运行状态时轮询，避免闲置请求。
- 图片按进入视口读取私有二进制并释放 Blob URL；标签翻译去重后分批请求。
- 图片快照变化会使旧确认失效，已经用于训练的数据集保持只读，以保证训练审计一致。

## 翻译集与标签颜色

- 已联网调研 `ffdkj/ffdkj-Danbooru_Tag-Chinese-English-Translation-Table` 与 `sw1313/danbooru-tags-translation`。前者没有声明数据许可证，后者由 GNU FDL、CC BY-NC-SA、社区翻译与 AI 翻译混合组成，因此生产服务不直接复制整库，也不依赖第三方仓库在线可用性。
- 独立平台建立自己的 `TrainingTagTranslation` 翻译集。部署时写入平台维护的常用训练标签；用户遇到未收录标签时调用现有提示辅助模型翻译，并把结果写回翻译集，后续所有用户直接复用。
- 每个规范化英文标签在后端分配一个持久化十六进制颜色；颜色列带唯一约束，发生哈希碰撞时自动换盐重算，因此刷新、换设备或进入另一训练集后仍保持同色。
- 翻译集保存标签、中文、颜色、来源和使用次数，不保存用户图片、训练集归属或提示词。
